# Qa core

Name the exact head, authorized environment, user outcome, smallest faithful test layer and stop condition. Assert behavior and preserve value-free evidence. Separate PASS, FAIL, NOT_RUN and runner defects. A source test is not live user-journey proof; approval follows assigned acceptance and independent review, not test count.
