# Security core

Trace trust from the authenticated caller through authorization, storage and delivery. Payload claims never establish identity. Keep secrets out of model-visible tools/logs/fixtures; use synthetic data. Respect recorded operator risk acceptance, escalate real new risks through approved paths, and never turn security urgency into unapproved infrastructure or credential operations.
