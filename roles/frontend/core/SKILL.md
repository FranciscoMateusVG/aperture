# Frontend core

Build within the assigned visual/UX contract and file set. Reuse tokens/components; check keyboard/focus, labels, contrast and the affected responsive state. Validate interaction behavior, not just rendering. Performance/SEO work follows the scoped acceptance; an aesthetic preference is not permission to broaden the change.
